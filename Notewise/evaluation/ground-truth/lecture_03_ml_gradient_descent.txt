In this lecture we analyze gradient descent optimization for training neural networks. The objective of gradient descent is to minimize a loss function by iteratively updating model parameters in the opposite direction of the gradient. The learning rate, denoted by alpha, controls the step size taken in parameter space. If the learning rate is chosen too small, gradient descent will take an excessive number of iterations to converge. If alpha is set too large, the algorithm can overshoot the global minimum and diverge completely. In standard batch gradient descent, the entire training dataset is evaluated at each step. In stochastic gradient descent, a single random training sample is used per step, introducing stochastic noise that helps escape saddle points.
