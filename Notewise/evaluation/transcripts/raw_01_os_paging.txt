Good morning class today we will dive deep into virtual memory management focusing on pacing architecture. Why do we need virtual memory in early computing programs were constrained by physical RAM size. Virtual memory separates user logical memory from physical memory each process is given an illusion of a contiguous address space. In pacing the logical address space is divided into fixed size blocks called pages typically four kilobytes. Physical memory is divided into fixed size blocks of the identical size called frames. The memory management unit uses a page table to translate logical page numbers to physical frame numbers. A page number acts as an index into the page table. When the processor accesses a page not currently present in RAM a page fault occurs. The OS traps to the kernel fetches the page from packing store into a free frame updates the page table valid invalid bit and restarts the instruction. Remember this for your midterms page fault handling involves disk IO which is orders of magnitude slower than memory access.
