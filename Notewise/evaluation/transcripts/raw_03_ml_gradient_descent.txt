In this lecture we analyze radiant descent optimization for training neural network. The objective of radiant descent is to minimize a lost function by iteratively updating model parameters in opposite direction of radiant. The learning rate denoted by elba controls step size taken in parameter space. If learning rate is chosen to small radiant descent will take an excessive number of iteration to converge. If elba is set to large the algorithm can overshoot global minimum and diverge completely. In standard batch radiant descent the entire training dataset is evaluated at each step. In stochastic radiant descent a single random training sample is used per step introducing sarcastic noise that helps escape saddle points.
